# SIX Bridge v0.1.0 preview 릴리스 노트

## 포함 기능

- 데스크톱에서 Chrome/Edge Manifest V3 확장의 호환성을 분석하고 `.sixdraft`를
  생성하는 SIX Bridge 앱
- Android 11 이상에서 `.six`를 가져와 호환성 보고서를 확인하고 확장별 래퍼
  APK 설치를 Android 시스템 화면으로 연결하는 관리자 앱
- 삼성 인터넷 30.x용 profile과 검증된 모바일 어댑터 경계

## 알려진 제한

- 모든 데스크톱 확장 API와 UX를 모바일 Samsung Internet에서 동일하게 제공하지
  않습니다. `blocked` 또는 `unknown` 결과는 설치할 수 없습니다.
- Android APK는 Google Play Protect 경고를 표시할 수 있으며, 설치 전 checksum과
  signer를 사용자가 확인해야 합니다.
- macOS DMG는 **미서명·미공증** preview이므로 Gatekeeper 경고가 표시될 수
  있습니다. Apple Developer ID 서명이나 Apple 공증을 받은 파일이 아닙니다.
- Windows MSI, Google Play/Galaxy Store 등록, 릴리스 바이너리 자동 업로드는 이
  preview 범위에 포함하지 않습니다.

설치와 확인 절차는 [공개 배포 안내](../RELEASE_KO.md)를 따르세요.
