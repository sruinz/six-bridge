# SIX Bridge v0.1.3 preview 릴리스 노트

## 삼성 인터넷 31.x 공식 지원

- 삼성 인터넷 `31.0.0.81`(`versionCode 1310081502`)의 실제 APK 증거(삼성 서명,
  래퍼 계약 마커 4종, 옵션 페이지 기능, 확장 API 69종)를 기준으로 공식
  baseline 프로필(`profiles/sbrowser-31.0.0.81.json`)을 추가했습니다.
- 기존 `30.x` baseline(`30.0.2.61`)과 `31.x` baseline(`31.0.0.81`)을 모두
  지원하는 다중 메이저 baseline 구조를 도입해, 삼성 인터넷이 `31.0.0.81`로
  업데이트된 기기에서 발생하던 `PROFILE_UNKNOWN`("설치된 삼성 인터넷의 변환
  계약을 확인하지 못했습니다") 오류를 해결했습니다.
- 데스크톱 앱 내장 프로필 카탈로그에도 `sbrowser-31.0.0.81.json`을 기본
  프로필로 포함했습니다.

## 브라우저 메이저 업데이트 간 확장 덮어쓰기 신원 유지

- 삼성 인터넷 메이저 버전이 `30.x`에서 `31.x`로 올라간 뒤 기존 확장을 다시
  변환할 때 새 패키지·새 확장 ID로 분리되지 않도록 신원 연속성을 개선했습니다.
- 안정 신원(`store:`, `manifest:`, `project:`)은 현재 메이저 키가 원장에 없을
  때 기존 `ACTIVE`(및 `PASSTHROUGH`/`PREPARED`의 `RETIRED`) 설치 신원을
  조회해 기존 `identitySha256`, `extensionId`, `packageName`, Android Keystore
  CRX 키를 그대로 재사용하며 `versionCode`만 올려 덮어쓰기 업데이트합니다.
- 불안정 ZIP의 기존 대상 선택(`UseExisting`) 목록도 이전 메이저 버전에서
  생성된 `ACTIVE` `CONVERTED` 대상을 함께 표시하고 재사용할 수 있도록
  확장했습니다.
- 데스크톱·CLI의 CRX 키 저장소(`ExtensionKeyManager`)도 이전 메이저 버전에서
  생성된 스토어 변환 키가 있으면 우선 재사용합니다.

## Android 관리자 업데이트 연속성

- application ID는 기존과 같은 `dev.sixbridge.manager`입니다.
- `versionName`은 `0.1.3`, `versionCode`는 `4`입니다.
- release signer SHA-256은 기존과 같은
  `419a3d2f645e6b25411d66a93ec793ab89ed4b32161dec5ed55298715a3da51e`입니다.
- 같은 package와 signer를 유지한 업데이트이므로 기존 앱 데이터·원장·Keystore
  서명 키를 유지한 채 그대로 덮어쓰기 설치할 수 있습니다.

## macOS preview

macOS 제품 버전은 `0.1.3`, native package version은 `1.0.3`이며 bundle ID는
`dev.sixbridge.desktop`입니다. DMG는 **미서명·미공증** preview이므로
Gatekeeper 경고가 나타날 수 있습니다. Apple Developer ID 서명이나 공증을
받은 배포본으로 간주하면 안 됩니다.

## 제품 산출물 경계

제품 릴리스 산출물은 다음 다섯 파일뿐입니다.

- `SIX-Bridge-Manager-0.1.3-android.apk`
- `SIX-Bridge-0.1.3-macos-unsigned.dmg`
- `SHA256SUMS`
- `RELEASE-METADATA.json`
- `RELEASE-NOTES-KO.md`

사용자 `.six`, `.sixdraft`, CRX, 특정 확장 소스·바이너리·변환 결과와 key는
제품 asset에 포함하지 않습니다. 저장소의 일반화된 fixture와 검증 script는
제품 기능을 검증하기 위한 것이며 특정 확장 데이터를 제공하는 배포물이
아닙니다.

설치, checksum과 signer 확인 절차는 [공개 배포 안내](../RELEASE_KO.md)를
따르세요. 기존 [v0.1.2 릴리스 노트](v0.1.2-ko.md), [v0.1.1 릴리스 노트](v0.1.1-ko.md)와
v0.1.0 자산은 수정하거나 교체하지 않습니다. 이 릴리스의 공개 source 기준 URL은
[GitHub v0.1.3](https://github.com/sruinz/six-bridge/tree/v0.1.3)입니다.
