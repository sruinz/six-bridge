# SIX Bridge v0.1.2 preview 릴리스 노트

## 제한적 UNKNOWN 강제 변환

- 원래 호환성 상태가 `UNKNOWN`이고 모든 blocking issue가 정확히
  `api_usage_dynamic`인 안전 분류 입력만 사용자가 **현재 작업에서 한 번**
  명시적으로 확인한 뒤 강제 변환할 수 있습니다.
- CLI에서는 일반 `--force`가 아니라 정확히
  `--force-compatibility-unknown`을 사용합니다. 옵션이 없으면 이전과 같이
  `UNKNOWN` 변환을 거부합니다. 데스크톱과 Android에서도 작업별 확인을 다음
  입력이나 다음 작업에 재사용하지 않습니다.
- 강제 결과도 원래 `UNKNOWN`, issue, 미검증 API와 서명된 provenance를
  보존합니다. `COMPATIBLE` 또는 `PARTIAL`로 바꾸지 않으며 실제 호환성을
  보증하지 않습니다.
- 다른 원인의 `UNKNOWN`과 모든 `BLOCKED`, profile 미검증, 분석 예산 초과,
  unavailable API·adapter, 구조·서명·경로·identity 불일치는 강제 승인으로
  우회할 수 없습니다.
- Android에서 강제 SixBundle을 가져온 뒤 실제 시스템 설치로 진행할 때는
  생성 승인과 별개의 설치 확인을 다시 요구합니다.

## Android 관리자 업데이트 연속성

- application ID는 기존과 같은 `dev.sixbridge.manager`입니다.
- `versionName`은 `0.1.2`, `versionCode`는 `3`입니다.
- release signer SHA-256은 기존과 같은
  `419a3d2f645e6b25411d66a93ec793ab89ed4b32161dec5ed55298715a3da51e`입니다.
- 같은 package와 signer를 유지한 업데이트이므로 버전마다 새 앱 소유권 인증을
  반복하지 않습니다. Google Play로 배포할 때는 기존 앱의 새 업데이트
  release로 업로드하고 해당 검토 절차를 거쳐야 하며, 로컬 직접 설치에는
  Play Console 업로드가 필요하지 않습니다.

## macOS preview

macOS 제품 버전은 `0.1.2`, native package version은 `1.0.2`이며 bundle ID는
`dev.sixbridge.desktop`입니다. DMG는 **미서명·미공증** preview이므로
Gatekeeper 경고가 나타날 수 있습니다. Apple Developer ID 서명이나 공증을
받은 배포본으로 간주하면 안 됩니다.

## 제품 산출물 경계

제품 릴리스 산출물은 다음 다섯 파일뿐입니다.

- `SIX-Bridge-Manager-0.1.2-android.apk`
- `SIX-Bridge-0.1.2-macos-unsigned.dmg`
- `SHA256SUMS`
- `RELEASE-METADATA.json`
- `RELEASE-NOTES-KO.md`

사용자 `.six`, `.sixdraft`, CRX, 특정 확장 소스·바이너리·변환 결과와 key는
제품 asset에 포함하지 않습니다. 저장소의 일반화된 fixture와 검증 script는
제품 기능을 검증하기 위한 것이며 특정 확장 데이터를 제공하는 배포물이
아닙니다.

설치, checksum과 signer 확인 절차는 [공개 배포 안내](../RELEASE_KO.md)를
따르세요. 기존 [v0.1.1 릴리스 노트](v0.1.1-ko.md)와 v0.1.0 자산은 수정하거나
교체하지 않습니다. 이 릴리스의 공개 source 기준 URL은
[GitHub v0.1.2](https://github.com/sruinz/six-bridge/tree/v0.1.2)입니다.
