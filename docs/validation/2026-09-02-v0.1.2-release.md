## Fold7 실사용 검증

사용자가 제공한 Chrome Web Store 확장을 v0.1.2 Android 관리자로 분석했다.
최초 호환성은 `UNKNOWN`이었고 blocking issue는 `api_usage_dynamic`이었다.
사용자가 이 작업에서만 유효한 명시적 강제 승인을 확인했다.

분석 결과 화면에서 기존 변환 대상의 package 또는 signer 불일치가 표시됐다.
저장소에 보존된 수동 테스트 APK의 signer와 현재 관리자 서명 경로를
비교한 결과, 같은 package에 다른 signer로 설치된 기존 래퍼가 Android의
업데이트 안전성 검사에 걸린 것으로 확인했다. 해당 래퍼를 제거한 다음
작업별 강제 승인 후 `.six` 생성과 확장 APK 저장·설치가 성공했다.
이 흐름은 v0.1.2 관리자 APK를 Fold7에 설치한 상태에서 수행했으며,
Samsung Internet에서 확장을 활성화한 후 실제 기능 실행까지 사용자가 확인했다.

이 검증은 확장의 호환성 판정을 `COMPATIBLE`이나 `PARTIAL`로 바꾸지 않는다.
결과는 여전히 `UNKNOWN`과 미검증 API, 이슈, 강제 승인 provenance를 유지한다.
사용자 입력 CRX·URL, 확장 바이너리, key, 비밀번호와 개인 경로는 저장소에
포함하거나 기록하지 않는다.

## 보존·배포 상태

- Samsung Internet APK는 수정하지 않았다.
- 기존 v0.1.0·v0.1.1 tag와 asset은 변경하지 않았다.
- v0.1.2 Forgejo/GitHub 원격 push, annotated tag, Release는 아직 시작하지 않았다.
- 본 기록을 포함한 최종 커밋에서 v0.1.2 exact-five 산출물을 다시
  생성·검증한다.
- v0.1.1/code 2에서 v0.1.2/code 3 업데이트와 앱 데이터 유지, Fold7의
  승인 없는 동일 입력 차단, 데스크톱 v4 draft의 Android strict import,
  동일 source/profile 업데이트 신원 연속성, 브라우저 재시작 유지는
  별도 수동 검증으로 남아 있다.
- 남은 수동 게이트가 완료되기 전에는 v0.1.2 릴리스 acceptance를 완료로
  표시하거나 원격 tag·Release를 게시하지 않는다.
